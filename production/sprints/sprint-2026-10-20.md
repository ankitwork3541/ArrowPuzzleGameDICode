## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| New package id breaks ad callbacks (`AndroidDataBridge` hard-codes the old host class) | Every paid event throws | Wrap in try/catch and read the class name from `Application.identifier`; coordinate the host rename. |
| `LevelTracker` posts the new game's wins to the old game's endpoint | Polluted analytics | Change the endpoint or add a game id before any release build. |
| Old save and prefs keys still `arrowqube*` | Fresh package id gives a fresh data folder, but keeping the old id would read the old save | Rename only with the new package id. Do not rename on its own, it would wipe existing players' progress. |
| Editor does not paint UI Toolkit unless it is the active app | UI cannot be screenshotted from the Editor | Windows dev player driven by `EvidenceCapture.cs` (`--evidence <dir>`), built with a detached job. |
| 424 of 1,500 levels are outside the 12% arrow-count tolerance | Ramp may feel uneven | The bake calls this harmless; playtest levels 6 to 60 for pacing. |
| Synthesised audio may sound thin | Weak feedback on win and unlock | Developer listens (task 4); regenerate or source real clips. |
| Contrast gaps: muted ink 3.96, dark gold 3.85, gold-orange fills 2.43 | Hard to read in sunlight | Listed in `design/accessibility-requirements.md`; one-line USS fixes. |
| 4-digit level title and small phones untested | Overlap or overflow on release | Task 8. |
